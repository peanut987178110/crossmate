# CrossMate 项目总览（README）

> 一个可本地运行、可测试、可讲解的**海外轻社交 App 原型**：18 个页面 + REST API v0.2 + 确定性 AI + 57 个接口测试 + 6 个 E2E + 12 个可点性测试 + 21 项安卓烟雾断言。  
> 定位：给准备「社交产品经理 / AI 产品经理」面试的人，一个能**从需求讲到实现再讲回数据**的完整案例。
>
> 文档版本 v0.2.4 · 最后更新 2026-11-18 · 上手先看仓库根目录的 [README.md](../README.md)

## 4. 技术栈与关键决策

| 决策 | 选择 | 为什么 |
|---|---|---|
| 后端 | FastAPI + Pydantic v2 | 自动 OpenAPI（`/docs`）、校验即文档、上手快 |
| 存储 | SQLite（单连接 + RLock，`db.tx()` 事务） | 零依赖、可复制、可测；`db.tx()` 隔离迁移到 PG 的成本 |
| 前端 | 原生 ES Module + hash 路由 | 无构建步骤，打开就能跑；适合演示与教学 |
| AI | `mock` 确定性实现 / `real` OpenAI 兼容网关 | 测试稳定；真实环境只需配环境变量 |
| 鉴权 | 邮箱验证码 + Bearer token | 无密码，适合海外用户；演示模式返回验证码 |
| 实时 | 3s 轮询 | 先保证正确性；WebSocket 列入 v0.3 |

## 5. 产品红线（有测试兜底）

1. AI 只给建议，**永不自动发送**（TC11 + E2E）。
2. AI **不冒充真人**、不输出“已替你发送”（TC12）。
3. 性别/取向/宗教/种族**不参与推荐**、不下发（TC39）。
4. **积分不影响推荐**，不能购买曝光（TC07/TC39）。
5. 无未成年人；18+ 双重确认（TC01 + E2E）。
6. 语音房/通话**不录音**、不回放、不转写。
7. 举报人身份不可见；举报只存脱敏证据（TC22/TC31）。
8. 日志不含邮箱、token、聊天原文（TC36）。

## 8. 安卓安装包（真机 / 模拟器，**离线自包含**）

`app-shell/` 是 Capacitor 原生壳，把 `web/` 装进 WebView，**并把后端一起打进去**：
Chaquopy 在 APK 里内嵌 CPython 3.12，App 启动时在本机 `127.0.0.1:8765` 跑起 FastAPI，
SQLite 落在 App 私有目录。所以：**装到手机上不连电脑、不连网络也能用**（飞行模式下已验证）。

```powershell
cd F:\CrossMate\app-shell
npm install                                        # 首次（装 Capacitor CLI）
npm run sync                                       # = sync-web.mjs + cap sync android
cd android; .\gradlew.bat assembleDebug
# 产物：app-shell\android\app\build\outputs\apk\debug\app-debug.apk（约 41 MB，实测 40.7 MB）
```

| 项 | 取值 | 为什么 |
|---|---|---|
| 嵌入运行时 | Chaquopy 16.1.0 + Python 3.12 | 必须显式写 `version "3.12"`，否则退回 3.8，代码里的 `list[str] | None` 会报错 |
| pydantic | **1.10.x（纯 Python）** | v2 的核心 `pydantic-core` 是 Rust，没有 Android wheel。业务代码统一走 `util.as_dict()`，v1/v2 各 57 个测试都通过 |
| minSdk | 24 | Chaquopy 要求 |
| abiFilters | `arm64-v8a`, `x86_64` | 覆盖主流真机与模拟器，体积减半 |
| 默认后端 | `http://127.0.0.1:8765/api/v0.2` | 由 `sync-web.mjs` 写进 `<meta name="cm-api-default">` |

**联调时想用电脑上的后端**（例如改 Python 不想重新打包）：启动 `backend`（`$env:HOST='0.0.0.0'`），然后

```powershell
adb shell am start -n app.crossmate.demo/.MainActivity -e cm_api "http://192.168.1.23:8000/api/v0.2"
```

地址写进 `localStorage.cm_api`，优先级高于默认值；清 App 数据即回到离线默认。

**后端地址是怎么注入的**（踩过坑，见测试报告 D14）：`app.js` 的 `const API` 在模块加载时就定死，所以地址必须在它之前写好。链路是 `sync-web.mjs` 写入 `<meta name="cm-api-default">` → `<head>` 里同步执行的 `js/shell.js` 读 localStorage / 该 meta 并写回 `cm-api` → `app.js` 才读取。**不要**在原生 `onStart` 里用 `evaluateJavascript` 改 meta：那时 WebView 还没有文档（尺寸 `0,0-0,0`），查询不到 meta，注入会静默失效，表现为"所有账号都登不上"。

**改完壳必须走完整构建**：只跑 `gradlew` 不会把 `www/` 拷进 assets，会打进旧前端。

**启动体验**（踩过坑，见 D17）：三处颜色都必须是品牌深色，否则冷启动会白屏 2~3 秒——

1. `AppTheme` 的 `android:windowBackground`（进程已起、Activity 主题未生效那一帧）；
2. `AppTheme.NoActionBarLaunch` 的 `windowSplashScreenBackground` —— 它默认取 `?android:colorBackground`，AppCompat Light 下是**白色**；
3. `MainActivity.onStart` 里 `webView.setBackgroundColor(0xFF0D0A13)`（系统启动画面退场到页面首帧之间的空档）。
   ——注意 `onStart` 只负责底色；后端地址注入走的是 `injectApi()`（Python 后端就绪后 + `onPageFinished` 各调一次）。

另外 `index.html` 头部有一行内联 `background`，保证 CSS 解析前也不白闪。图标与启动图（`mipmap-*`、`drawable-*/splash.png`、`drawable-*/splash_icon.png`）均为品牌色生成图。

**验证脚本** `app-shell/tools/smoke_android.py`：通过 WebView CDP 在**真实 App** 里跑 21 项断言（地址注入并真实请求后端、骨架渲染、登录、Discover 可解释文案、双向喜欢→匹配、AI 只回填不发送、积分页声明等）。离线验证时必须**先关掉电脑上的 `backend`**（否则可能 200 掩盖问题——App 默认访问 127.0.0.1:8765，不会误连 8000，但 smoke 的期望值要对应）。

> 构建环境：JDK 17 + Android SDK（写在 `android/local.properties`）、NDK 26.1.10909125、cmake 3.22.1。Gradle 走腾讯云镜像（公司网络拦截 gradle.org 的 TLS）。
